# DataBank DePIN Bandwidth Marketplace

Quantum Coders Team | HACK INDIA 2026

Decentralized bandwidth marketplace powered by blockchain for MST Testnet.

## Components

- Android App - Kotlin/Jetpack Compose marketplace
- Smart Contracts - Solidity blockchain integration  
- Web Explorer - MST Testnet viewer

Address: 0x89A3192f150BbcF8A5D6B6904124976725B3d4B2

## Project Structure

- android/ - Kotlin/Compose application
- contracts/ - Solidity smart contracts
- website/ - Web-based explorer
- docs/ - Documentation files

## Technologies

- Android: Kotlin 2.1.0, Jetpack Compose, Hilt, Firebase
- Contracts: Solidity 0.8.19, Hardhat  
- Website: HTML5, CSS3, JavaScript
